# Security Policy

## Supported versions

This repository is a draft reference profile. Security fixes apply to the latest `main` branch until versioned releases begin.

## Reporting a vulnerability

Please do not open public issues for suspected vulnerabilities. Email security@pheo.ai with:

- affected file or schema
- reproduction steps
- expected and actual behavior
- potential impact

We will acknowledge receipt within 5 business days during the private review phase.

## Security scope

This profile emits references, digests, and decision metadata. It is not a signing service, identity provider, sandbox, or compliance certification.
