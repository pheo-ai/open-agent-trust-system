# Governance

This repository is a draft interoperability contribution intended for private community review before any public upstream discussion.

## Current maintainers

- Pheo maintainers during private review

## Decision principles

- Keep the profile vendor-neutral and useful without any commercial runtime.
- Prefer compatibility with OpenSharing, MCP, DSSE, in-toto, SLSA, and Sigstore terminology.
- Keep portable documents minimal: identifiers, references, digests, decisions, and lifecycle metadata.
- Do not require raw customer data in portable documents.
- Promotion requires explicit authorization; demotion must fail safe.

## Future governance

If the project is proposed for broader community adoption, maintainership should move toward an open technical steering model with documented contribution and release rules.
